# Bakers Choice – Desktop Application

Bakers Choice is a desktop bakery e-commerce and learning application designed to allow users to browse bakery products, add items to cart, and learn baking through tips and content.

## Project Objective

The goal of this project is to design and build a scalable, user-friendly desktop application with a clean UI and reusable components, following a UI-first development approach.

## Design Phase

- Initial layouts sketched on paper
- Wireframes created and finalized in Figma
- Common layout structure with header, sidebar, and footer
- Product listing page designed with pagination (6 items per page)
- Navigation flow prototyped between screens

## Functional Requirements

User can login/signup
User can view homepage with carousel
User can browse products
User can add products to cart
User can view cart items
User can checkout and make dummy payment
User can submit feedback (Contact Us)
User can view About Us page
User can logout

## Baker’s Choice – User Stories

As a user, I want to login to the app so that I can access features
As a user, I want to view bakery items so that I can choose products
As a user, I want to add items to cart so that I can purchase them
As a user, I want to view my cart so that I can manage items
As a user, I want to checkout so that I can complete my order
As a user, I want to make a payment (dummy) so that I can simulate purchase
As a user, I want to submit feedback so that I can share my experience
As a user, I want to view About Us so that I know about the business
